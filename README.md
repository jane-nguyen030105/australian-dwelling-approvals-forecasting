# Australian Dwelling Approvals Forecasting

## Project Overview

This project analyses historical Australian dwelling approvals data from the Australian Bureau of Statistics (ABS) and develops a forecasting model for the following 12 months.

The analysis focuses on identifying trend and seasonal patterns, developing a Winters Exponential Smoothing model, optimising model parameters and evaluating forecast performance.

## Tools

- Microsoft Excel
- Excel Solver

## Methods

- Time-series analysis
- Winters Exponential Smoothing
- Parameter optimisation
- Forecast-error evaluation
- Actual-vs-forecast comparison

## What I Did

- Prepared historical ABS dwelling approvals data for forecasting.
- Examined trend and seasonal patterns in the time series.
- Developed a multiplicative Winters Exponential Smoothing model.
- Used Excel Solver to optimise model parameters by minimising mean squared error.
- Evaluated forecasting performance using MSE, MAE and MAPE.
- Compared forecasts with actual out-of-sample observations.
- Interpreted model performance, limitations and business implications.

## Key Result

Parameter optimisation reduced the model's MSE from approximately 5.16 million to 3.82 million. The analysis also identified remaining patterns that were not fully captured by the forecasting model.
